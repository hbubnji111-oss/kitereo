# KITEREO — Инструкция по управлению сайтом

Этот документ объясняет как обновлять содержимое сайта без знания программирования.
Все изменения делаются прямо на GitHub — никаких программ устанавливать не нужно.

---

## Быстрый старт

1. Зайдите на страницу репозитория на GitHub
2. Откройте файл **`content.js`** (нажмите на него)
3. Нажмите кнопку с иконкой карандаша ✏️ (Edit this file)
4. Внесите изменения
5. Нажмите зелёную кнопку **"Commit changes"** → ещё раз **"Commit changes"**
6. Подождите ~1 минуту — сайт обновится автоматически

---

## Что можно менять в `content.js`

### 👥 Команда
Найдите раздел `team:` — там список сотрудников.

**Один человек в команде** — оставьте только один блок:
```
team: [
  {
    initial: "А",
    nameEn:  "Alexey Ivanov",
    nameRu:  "Алексей Иванов",
    role:    "Founder & Creative Director",
  },
],
```

**Добавить нового сотрудника** — скопируйте блок `{ ... },` и вставьте ниже.

**Удалить сотрудника** — удалите весь блок от `{` до `},` включительно.

---

### 💼 Кейсы / Портфолио

Найдите раздел `cases:`. Карточки располагаются на сайте так:

```
┌─────────────────┬─────────────────┐
│    Кейс 1       │    Кейс 2       │
│ (верхний левый) │ (верхний правый)│
├─────────────────┼─────────────────┤
│    Кейс 3       │    Кейс 4       │
│ (нижний левый)  │ (нижний правый) │
└─────────────────┴─────────────────┘
```

Каждый блок в `content.js` помечен комментарием — `// ── Кейс 1`, `// ── Кейс 2` и т.д.

Для каждого проекта заполните:
- `titleRu` / `titleEn` — название проекта
- `tagRu` / `tagEn` — тип работы (Видео, Реклама, Дизайн...)
- `year` — год
- `descRu` / `descEn` — короткое описание (1–2 предложения)
- `videoUrl` — ссылка на YouTube, если это видеопроект
- `imageUrl` — фото-обложка, если нет видео
- `link` — куда ведёт клик (если нет видео)

---

### 🎬 Добавить видео в кейс

**Вариант A — свой видеофайл (mp4/webm):**

Видео будет играть прямо на карточке — зациклено, без звука, как живая обложка.

1. На странице репозитория нажмите на папку **`images/`**
2. Нажмите **"Add file" → "Upload files"**
3. Перетащите видеофайл (MP4, WebM) → **"Commit changes"**
4. В `content.js` укажите путь:
```
videoUrl: "images/project1.mp4",
```

> Совет: называйте файлы латиницей без пробелов, например `project-reklama-2025.mp4`

**Вариант B — YouTube:**

На карточке появится превью из YouTube с кнопкой ▶. При клике откроется видео.

1. Вставьте ссылку на YouTube в поле `videoUrl`:
```
videoUrl: "https://youtu.be/XXXXXXXXXX",
```

Поле `imageUrl` при этом можно оставить пустым — превью берётся автоматически.

---

### 🖼️ Добавить фото-обложку в кейс

Оставьте `videoUrl: ""` и заполните `imageUrl`. Три варианта:

**Вариант 1 — загрузить файл на GitHub (папка `images/`):**
1. На странице репозитория нажмите на папку **`images/`**
2. Нажмите **"Add file" → "Upload files"**
3. Перетащите фото (JPG, PNG, WebP) → **"Commit changes"**
4. В `content.js` укажите: `imageUrl: "images/название-файла.jpg"`

> Совет: называйте файлы латиницей без пробелов, например `project-ivanov-2025.jpg`

**Вариант 2 — Google Drive:**
1. Загрузите фото на Google Drive
2. Правая кнопка → **"Открыть доступ"** → **"Все у кого есть ссылка"** → Копировать ссылку
3. Вставьте в `content.js`:
```
imageUrl: "https://drive.google.com/file/d/XXXXXXXXXXXXXXX/view",
```
Сайт автоматически конвертирует ссылку — ничего дополнительного делать не нужно.

**Вариант 3 — любая прямая ссылка на фото из интернета:**
```
imageUrl: "https://example.com/photo.jpg",
```

**Нет ни фото ни видео** — оставьте оба поля пустыми: будет тёмный градиент-заглушка.

### 🎬 Шоурил (видео справа в блоке "О нас")

Найдите раздел `showreel:`. Три варианта для правой колонки:

**Вариант A — свой видеофайл (играет зациклено и без звука):**
1. Загрузите файл в папку `images/` (как описано выше)
2. Укажите путь:
```
videoFileUrl: "images/showreel-2025.mp4",
youtubeUrl: "",
```

**Вариант B — YouTube:**
```
videoFileUrl: "",
youtubeUrl: "https://youtu.be/XXXXXXXXXX",
```

**Вариант C — заглушка "Скоро":**
```
videoFileUrl: "",
youtubeUrl: "",
```

- Поставьте `show: false` — блок исчезнет полностью

### 🏷️ Клиенты (бегущая строка)

Найдите раздел `clients:` — просто список названий.
Добавляйте и удаляйте строки как хотите.

---

### 🔗 Соцсети и контакты

Найдите разделы `socials:` и `contacts:`.
Вставьте полные ссылки. Пустое поле `""` — иконка или ссылка скрыта.

```
socials: {
  instagram: "https://instagram.com/ваш_аккаунт",
  youtube:   "https://youtube.com/@ваш_канал",
},
contacts: {
  email:    "ваш@email.com",
  telegram: "https://t.me/ваш_username",
  whatsapp: "https://wa.me/79001234567",
},
```

---

## ⚠️ Важные правила редактирования

- Меняйте только текст **внутри кавычек** `" "`
- Не удаляйте **запятые** `,` в конце строк
- Не удаляйте **скобки** `{ }` и `[ ]`
- Если что-то сломалось — напишите разработчику, он восстановит за минуту

---

## Пример правильного редактирования

**До:**
```
titleRu: "Brand 01 — Music Video",
```

**После:**
```
titleRu: "Иванов & Co — Летний клип",
```

Поменяли только текст между кавычками. Запятая осталась. ✅
